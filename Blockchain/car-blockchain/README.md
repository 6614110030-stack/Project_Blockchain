# Car-Blockchain 🚗⛓️

ระบบบันทึกประวัติการบำรุงรักษารถยนต์บนเทคโนโลยี Blockchain

## 📋 คำอธิบายโครงการ

**Car-Blockchain** เป็นแอปพลิเคชันที่ใช้เทคโนโลยี Blockchain เพื่อบันทึก และติดตามประวัติการบำรุงรักษารถยนต์ อย่างปลอดภัย และโปร่งใส โดยแต่ละการบำรุงรักษาจะถูกบันทึกในบล็อกที่เชื่อมโยงกัน เพื่อให้ 確็นใจได้ว่าข้อมูลไม่สามารถแก้ไขหรือลบได้

### 🎯 วัตถุประสงค์
- ✅ บันทึกประวัติการบำรุงรักษารถยนต์อย่างปลอดภัย
- ✅ สร้างความโปร่งใสในการให้บริการวิศวกรรม
- ✅ ป้องกันการปลอมแปลงข้อมูลการบำรุงรักษา
- ✅ ให้การยืนยันข้อมูลอย่างเชื่อถือได้ผ่าน Blockchain

## 🚀 คุณสมบัติหลัก

### 1. **ระบบ Blockchain**
   - บล็อกธรรมชาติที่มีความปลอดภัย
   - ธุรกรรมที่ลงนามด้วยข้อมูลประวัติการบำรุงรักษา
   - นัยว่าบล็อกแต่ละบล็อกจะมีการเชื่อมโยงกับบล็อกก่อนหน้า

### 2. **ระบบผู้ใช้**
   - บทบาท: Garage (ศูนย์บริการ) และ Admin
   - การสมัครสมาชิกและเข้าสู่ระบบที่ปลอดภัย
   - แต่ละศูนย์บริการมีชื่อร้านค้าของตนเอง

### 3. **การจัดการรถยนต์**
   - บันทึกรถยนต์โดยใช้เลขประจำตัวรถ (VIN)
   - ติดตามประวัติการบำรุงรักษา
   - บันทึกการบ่มอากาศและรายละเอียดการบำรุงรักษา

### 4. **Web Interface**
   - หน้าแดชบอร์ดเพื่อดูบล็อกเชน
   - ค้นหารถยนต์ตามหมายเลข VIN
   - เพิ่มการบำรุงรักษาใหม่
   - ดูประวัติการบำรุงรักษา

## 🛠️ การติดตั้ง

### ความต้องการ
- **Node.js** (v14 หรือสูงกว่า)
- **npm** (Node Package Manager)

### ขั้นตอนการติดตั้ง

1. **โคลนเก็บข้อมูล**
   ```bash
   git clone https://github.com/6614110030-stack/Project_Blockchain.git
   cd car-blockchain
   ```

2. **ติดตั้งไลบรารี**
   ```bash
   npm install
   ```

3. **รันเซิร์ฟเวอร์**
   ```bash
   node server.js
   ```
   เซิร์ฟเวอร์จะเริ่มทำงานบน `http://localhost:3000`

4. **เปิดในเบราว์เซอร์**
   ```
   http://localhost:3000
   ```

## 🔐 ความปลอดภัย

- ✅ ใช้ SHA-256 สำหรับการแฮชบล็อก
- ✅ บล็อกแต่ละบล็อกมีการเชื่อมโยงกับ Hash ของบล็อกก่อนหน้า
- ✅ การเปลี่ยนแปลงข้อมูลใด ๆ ในอดีตจะทำให้ Hash เปลี่ยนไป

## 📖 วิธีการใช้งาน

### 1. **สมัครสมาชิก**
   - ไปที่หน้า Register
   - ป้อนชื่อผู้ใช้ รหัสผ่าน และชื่อร้านค้า (สำหรับ Garage)
   - คลิก "สมัครสมาชิก"

### 2. **เข้าสู่ระบบ**
   - ไปที่หน้า Login
   - ป้อนชื่อผู้ใช้ และรหัสผ่าน
   - คลิก "เข้าสู่ระบบ"

### 3. **บันทึกประวัติการบำรุงรักษา**
   - ไปที่หน้า "Add" (เพิ่มประวัติการบำรุงรักษา)
   - ป้อน VIN ของรถยนต์
   - ป้อนรายละเอียดการบำรุงรักษา (ความเสียหาย เปลี่ยนน้ำมัน ฯลฯ)
   - ป้อนจำนวนไมล์ที่วิ่ง
   - คลิก "บันทึก"

### 4. **ค้นหารถยนต์**
   - ไปที่หน้า "Search"
   - ป้อนหมายเลข VIN
   - ดูประวัติการบำรุงรักษาทั้งหมด

### 5. **ดูแดชบอร์ด**
   - ไปที่หน้า "Dashboard"
   - ดูบล็อกทั้งหมดใน Blockchain
   - ดูจำนวนบล็อก ธุรกรรม และสถานะของระบบ

## 📊 ตัวอย่าง API Endpoints

```javascript
// เข้าสู่ระบบ
POST /api/login
Body: { "username": "garage1", "password": "password123" }

// ลงทะเบียนผู้ใช้ใหม่
POST /api/register
Body: { "username": "garage2", "password": "pass123", "role": "garage", "shopName": "ศูนย์บริการ XYZ" }

// เพิ่มการบำรุงรักษา
POST /api/addTransaction
Body: { "vin": "ABC123456", "detail": "เปลี่ยนน้ำมัน", "mileage": 50000 }

// ค้นหา VIN
GET /api/search?vin=ABC123456

// ดู Blockchain
GET /api/blockchain
```
